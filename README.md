# Conecta Nexus - Piloto `auth-service` (UFPS)

Plataforma de conexión académico-empresarial - Universidad Francisco de Paula Santander (UFPS, Cúcuta).
Microservicio piloto de **Identidad, Seguridad y Cumplimiento (`auth-service`)**.

## Componentes del Proyecto

- `backend/`: Microservicio REST desarrollado con Django 5, DRF y SimpleJWT.
- `frontend/`: Aplicación web SPA/SSR desarrollada con Nuxt 4, Vue 3, Vite y Tailwind CSS (gestionada con `pnpm`).
- `infra/`: Aprovisionamiento de infraestructura en Google Cloud Platform (GCP) con Terraform.
